# The Work:
A mobile app software to manege a daily-house activities.

Target Audience: Busy homeowners looking to keep their household organized in one place.

Value Proposition: A single mobile-first dashboard to streamline chores, maintenance, finances reducing mental load.

## Features

### Module 1: Household Dashboard (Home Screen)
- Quick Status: Shows today's tasks (and upcomming ones in the next 7 days if the task is marked as High-Priority), upcoming bills, and Items expiring soon.
- Emergency Info: Quick access to important notes.
- Quick-Add Button (+): Floating button to instantly log a new bill, task, note, or item from anywhere in the app.
- Warnings: Overspend, Overdue tasks, Overdue Bills, Low stock, Item nearing expiry.

### Module 2: Task Management
- Recurring Schedules: Set daily, every X days, weekly, or monthly task routines.
- Categories: Flexible tagging (e.g., Cleaning, Maintenance, Personal, Study).
- Completion History: Simple streak tracker (of the last 7 days).
- Warning for not done tasks and upcomming tasks in the next 7 days (if the task is marked as High-Priority)
- A "Snooze (1 Day / 1 Week)" or "Skip This Instance" feature button so users can postpone a recurring task (will not change that task schedule)

### Module 3: Finance & Expenses
- Bill Tracker: add and manage bills (routine or one time pay, status, due date, amount, category like fixed price bill or variable one).
- Budgeting: Overview of monthly total income and household spending.
- In a bill: Mark as Paid as quick toggle that updates the bill status and updates the monthly budget total.
- Warning about Overspending and Overdue Bills
- Instead of permanently deleting paid bills, include an "Archive" state to keep historical records without cluttering active screens.

### Module 4: Notes
- User can create note pages
- Notes can be set to ~Pinned~ / ~High-Priority~ category to be showed in the home screen

### Module 5: Inventory
- Items that can end.
- Items got: status (In Stock, Low, Empty) and can be marked as Exhaustible itens (i.e Yogurt, medicines) and the expiration date.
- Low Stock Alert: Automatic prompt when status changes to "Low" or "Empty" asking: "Add to Shopping List?"

### Module 6: Shopping Cart
- Grocery List: list that can add items to the cart to buy.
- Check the inventory to warn for possible duplicates
- Out of Stock Trigger: When an inventory item is marked "Low" or "Empty," the app should offer a 1-tap "Add to Shopping List" button.
- When a item is added, show an option to add this item to the inventory, if so, then start to keep track of this item.
- Restock Automation: When an item on the Shopping List is checked off as bought, the app should automatically update its status back to "In Stock" in your Inventory.
- Automatically group shopping list items by category (e.g., Produce, Dairy, Cleaning, Pantry).
- Estimated Cost field to shopping items and a total cart cost.

### Module 7: Calendar
- Calendar that displays due dates generated by other modules, such as recurring tasks rotations and upcoming bill payment dates.
- Filter toggles: Show Bills Only, Show Chores Only, Show Expirations Only

### Module 8: Notifications
- Notifies about upcomming tasks, bills and Items with expiration dates.
- Notification Tab to see all notifications.
- "Attention Required" Collapsible Banner at the top of the dashboard (home screen). Tapping it expands a summary list (e.g., "3 Items Low, 1 Bill Overdue").
- Warnings: Overspend, Overdue tasks, Overdue Bills, Low stock, Item nearing expiry.
- "Daily Morning Briefing" push notification (e.g., at 8:00 AM: "Good morning! You have 2 chores today and 1 bill due tomorrow").
- Notification Preferences: 
    - Notification Channels: Individual toggles for Bill Due Dates, Chore Reminders, and Inventory Expirations.
    - Quiet Hours / Do Not Disturb: Mute push notifications during specified hours (e.g., 10:00 PM – 7:00 AM).
    - Daily Digest Timing: Choose the exact time to receive the daily morning summary push notification (e.g., 8:00 AM).

### System Options:
- Light and Dark mode
- Language options
- Change Currency
- Time format (12h/24h)
- Biometric Unlock / PIN Lock: Enable Face ID, Touch ID, or a 4-digit passcode upon opening the app.
- Add an "Export Backup (JSON)" or "Cloud Backup" toggle (e.g., back up to iCloud / Google Drive) so personal data can be restored easily.
- Import Backup: Restore data seamlessly from a previously exported .json backup file.
- Storage & Cache Cleaner: A 1-tap option to clear local temporary cached images/files without deleting active user data.
- Factory Reset / Clear All Data: A red-zone action to erase all app data with a safety confirmation prompt.
- Auto-Archive Threshold: Set a timeframe for automatically archiving completed chores or paid bills (e.g., After 30 days, 60 days, Never).
- Feedback / Bug Report Tab: Quick link or pop-up form to send logs or suggestions.
- App Info & Legal: App build version number, Terms of Service, and Privacy Policy.

## The system design
- The Two-Tier Storage Strategy

### Data Engine	SQLite (or Object DB):	
- Tasks, Bills, Inventory, Notes, Shopping Cart, Calendar events
- Needs SQL query capabilities (filtering, sorting, relational joins, search, and bulk updates).

### Settings Engine	Key-Value / Secure Store:
- System Options (Theme, Language, Currency, PIN Lock, Quiet Hours)	
- Fast, light, instant reading on app startup without querying a database.

All tables need these fields:
    id integer [ pk, UUID, not null ]
    created_at timestamp [ not null ]
	created_by userId [ not null ]
    updated_at timestamp [ not null ]
	updated_by userId [ not null ]

Table user {
    name
    email /* not needed fow now, but good to already have a field for this */
    password /* not needed fow now, but good to already have a field for this */
}

Table tb_user_preferences {
	userid
	monthly_income real
	currency_type varchar(3) not null /* standard ISO 4217 3-letter codes (BRL, USD, EUR) */
	time_format type_time_format [ not null, default: "12h" ] /* Like 12h/24h. Verify the better aprouch */
	timezone varchar(255) not null /* Standard IANA timezone strings (i.e America/Sao_Paulo) */
    theme type_theme [ not null, default: "dark" ] /* enum like to store this preference */
	language type_language [ not null, default: "pt-br" ] /* Like pt-br or en . Enum like to store this preference, for now only pt-br*/
}

Table tb_task_rule {
	title not null
	categoty varchar(255)
	is_high_priority boolean default: false
	recurrence_rule /* week, month, year or every X days */
}

Table tb_task {
	rule not null /* a tb_task_rule reference */ 
	due_date timestamp
	is_completed boolean default: false
}

Table tb_bill_rule {
	title [ not null ]
	category varchar(255)
	is_high_priority boolean default: false
	recurrence_rule /* type_recurrence_rule */
	default_amount real default: 0 
}

Table tb_bill {
	rule not null /* a tb_bill_rule reference */
	due_date timestamp
	is_paid boolean default: false
	amount real default: 0 
}

Table tb_inventory {
	name varchar(255) not null
	category varchar(255)
	status /* IN_STOCK, LOW, EMPTY */
	is_perishable boolean default: false
	expiration_date timestamp
}

Table tb_shopping_cart_item {
	inventory_id /* an optional reference to tb_inventory, on delete set NULL */
	name varchar(255) not null
	category varchar(255)
	estimated_cost real default: 0
	is_bought boolean default: false 
}

Table tb_notes {
	title varchar(255) [ not null ]
	content /* the file itself, or a reference to it, .MD file? */
	is_pinned boolean default: false
}
